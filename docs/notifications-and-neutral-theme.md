# Нейтральная тема и уведомления

## Поведение

- Светлая палитра: белые и нейтральные светлые поверхности, приглушённый лавандовый акцент. Тёмная: фон `#181818`, поверхности `#252525` / `#282828`, без зелёного оттенка. Основные кнопки графитовые. Исходные формы иконок сохранены, унифицированы штрих и подложка. Цвет значка установленного приложения также обновлён.
- В запасе поле **«Напомнить о покупке при остатке»** задаёт существующий `threshold`. При `quantity <= threshold` и отсутствии архива запас появляется в блоке **«Пора купить»** под напоминанием ухода на главной. Условие одинаковое со списком запасов; нулевой порог означает напоминание при нулевом остатке. Пополнение выше порога или архивирование убирает карточку.
- Изменение запаса обновляет главную; автоматическое списание при кормлении уже обновляет её. Другой участник семьи увидит изменения при обычном обновлении экрана/возвращении в приложение; realtime не добавлялся.
- Колокольчик **на главной** открывает модальный список поверх страницы, а не календарь. В «Ещё» повторный колокольчик убран; календарь остаётся отдельной нижней вкладкой.
- Список включает текущие покупки семьи и ближайшие напоминания каждого питомца по лекарствам, здоровью, кормлению и активности. Это текущие напоминания, не архив всех прошлых событий и не push при закрытом приложении.
- Красный счётчик показывает непрочитанные элементы. Ссылка открывает нужную запись и отмечает уведомление прочитанным. Есть отдельные кнопки «Отметить прочитанным» и «Прочитать все». Прочтение не выполняет уход и не убирает задачу покупки с главной.
- Прочтение хранится на устройстве, отдельно для аккаунта и семьи. Хранятся только идентификаторы, не тексты и не данные питомцев. Между вкладками браузера состояние обновляется через `storage`; между устройствами не синхронизируется. Если хранилище недоступно, действует память текущего сеанса.
- Идентификатор покупки включает версию запаса: изменение запаса создаёт новое непрочитанное уведомление, если остаток всё ещё низкий. Идентификатор ухода привязан к записи и запланированному времени, поэтому новый приём не наследует прочтение предыдущего.
- Все новые подписи доступны на русском и английском. Native dialog поддерживает клавиатурный фокус, Escape, закрытие кнопкой и нажатием вне панели.

## Данные и проверки

Схема базы и правила доступа не менялись. Чтение ограничено выбранной семьёй и существующим RLS. Запрос использует постраничное чтение, чтобы не терять строки из-за лимита API. Ошибка загрузки отображается явно и не маскируется под отсутствие уведомлений.

Проверено:

- Production build / TypeScript, HTTP smoke для RU/EN, тем и защищённых маршрутов.
- 44 автоматических теста, включая границу порога, пополнение, архив, прочтение, новые версии запаса, рендер модального списка и красного счётчика, прежние сценарии и контраст палитр.
- Read-only SQL в рабочей базе подтвердил наличие низкого запаса и отсутствие расхождения `is_low` с `quantity <= threshold`. Записи не изменялись.
- ESLint: 0 ошибок, 3 прежних предупреждения об изображениях.

Браузерный визуальный прогон и реальные клики по диалогу в этой среде не выполнены: ранее локальный адрес был недоступен облачному браузеру. Автоматические проверки рендера не заменяют такой прогон.

Обновление: `git fetch origin`, `git merge origin/codex/-petfolio`, `npm.cmd ci`, `npm.cmd run build`, `npm.cmd start`. SQL вручную запускать не нужно.
