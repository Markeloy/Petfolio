# Общий календарь

Доступ: нижнее меню → «Календарь», маршрут `/calendar`.

Обновление: календарь также включает ежедневные кормления и их отметки из раздела «Питание»; см. `docs/feeding-workflow.md`.

Также подключены планы, выполненные и отменённые записи активности; архивные записи скрыты. См. `docs/activity-workflow.md`.

- Выбор дня в сетке месяца или поле даты, переход между месяцами, кнопка «Сегодня».
- Все питомцы текущей семьи или выбранный питомец; фильтры сохраняются в адресе, доступны назад/вперёд браузера.
- События здоровья по дате, отдельные повторные процедуры по `next_due_on`, статусы выполнения и отмены. Архивные записи исключены.
- Сегодня и в будущем — приёмы по действующим ежедневным расписаниям с учётом дней недели, границ курса, версий расписаний и часового пояса. Приостановленные/завершённые курсы не создают план.
- Сохранённые «Дано»/«Пропущено» заменяют план, сохраняют снимок дозировки и видны после завершения курса. Прошлые дни содержат только фактические отметки лекарств: история изменения статуса курса не позволяет надёжно восстановить неотмеченные приёмы.
- Время отображается в часовом поясе профиля. События здоровья имеют только дату. Учтены переходы летнего времени и несовпадение дня в часовом поясе лекарства и пользователя.
- Переход к подробностям записи, добавление событий здоровья и переход к лекарствам каждого выбранного питомца. Приём отмечается на существующем экране лекарства в день приёма по его расписанию.
- Загрузка, понятная ошибка с повтором, пустой день, автообновление при возвращении в окно и раз в минуту. Изменение лекарств и здоровья сбрасывает кеш календаря.
- Запросы выполняются с пользовательской сессией и существующими RLS; таблицы и права не менялись. Постраничное чтение исключает тихое обрезание списка лимитом API.

Проверки: `npm run typecheck`, `npm run build`, `node --test tests/*.test.mjs` (19 проверок), `tests/calendar-database.sql` (транзакционные данные откатываются). Проверка интерфейса в браузере не проводилась.

Ограничения: сетка месяца служит выбору даты, не показывает количество событий по дням; уведомления вне приложения и интервальные расписания не добавлены. Запасы и семья в нижнем меню пока остаются заглушками. Это завершение календарного блока, не всего приложения.
